Arquitectura SET

ComponenteFunción
Base de ConocimientosUnión de aserciones y reglas. Contiene el conocimiento del dominio.
Base de DatosDatos del problema particular que se intenta resolver.
Memoria de TrabajoBase temporal donde el motor deja información deducida.
Motor de InferenciasActiva reglas usando base de datos y memoria de trabajo. Produce nueva información.
Trazador de ConsultasFormula consultas al usuario y registra respuestas en memoria de trabajo.
Trazador de ExplicacionesExplica por qué se concluyó o consultó algo, usando reglas provistas por el motor.
Manejador de ComunicacionesInterfaz de entrada/salida con el usuario.

Trampa de parcial

En un SET la base de conocimientos almacena hechos, aserciones y reglas. Los métodos de búsqueda sirven para recorrer/aplicar ese conocimiento, pero el componente que los ejecuta es el motor de inferencias. La memoria de trabajo guarda inferencias y el trazador de explicaciones justifica el resultado.
