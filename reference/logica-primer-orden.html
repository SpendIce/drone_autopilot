Lógica de Primer Orden

Chuleta para traducir frases del parcial a LPO sin mezclar cuantificadores.

Piezas

PiezaUsoEjemplo
VariableObjeto indeterminadox, y, z
ConstanteObjeto determinadoa, b, c
PredicadoPropiedad o relaciónP(x), T(x, y)
UniversalPara todo∀x
ExistencialExiste al menos uno∃x
OperadoresConectan hechos¬, ∧, ∨, →, ↔

Regla de traducción

FrasePatrónLectura
Todos los A son B∀x (A(x) → B(x))Si x es A, entonces x es B.
Algunos A son B∃x (A(x) ∧ B(x))Hay un x que es A y B.
Ningún A es B∀x (A(x) → ¬B(x))Todo A queda fuera de B.
Algún A no es B∃x (A(x) ∧ ¬B(x))Hay un A que no cumple B.

Proceso

  1. Detectar dominio.
  2. Nombrar propiedades y relaciones.
  3. Elegir cuantificador principal.
  4. Usar → con ∀ y ∧ con ∃, salvo que la frase diga otra estructura explícita.
  5. Leer la fórmula en castellano para comprobar equivalencia.

Ejemplos clave

FraseFórmula
Todas las personas trazan círculos.∀x∃y (P(x) → (T(x, y) ∧ C(y)))
Algunas serpientes no son venenosas.∃x (S(x) ∧ V(x))
