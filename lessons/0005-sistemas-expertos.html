Sistemas Expertos: reglas, inferencia y explicación

Esta lección cierra la afirmación 4 del V/F y ordena la arquitectura de un Sistema Experto Tradicional. El objetivo es que puedas justificar dónde se aplican los métodos de búsqueda y por qué un SET no es una RNA ni un AG. ~10 min.

Mapeo al parcial Afirmación 4: "Los Métodos de Búsqueda se aplican en un Sistema Experto Tradicional dentro de la Base de Conocimientos." La marca clave de la profe fue: se aplican en el motor de inferencias.

1. Qué hace experto a un SET

Un Sistema Experto intenta emular parte del comportamiento de un experto humano en un dominio. Cuando ese conocimiento está escrito de forma explícita como hechos, aserciones y reglas, la cátedra habla de Sistema Experto Tradicional (SET).

Idea central Un SET no aprende pesos como una RNA ni optimiza poblaciones como un AG. El SET razona recorriendo conocimiento explícito: usa reglas, datos del caso y memoria de trabajo para inferir nueva información y explicar el resultado.

2. Los siete componentes que importan

La fuente de componentes lista siete piezas. Aprendelas por función, no como nombres sueltos:

Base de Conocimientos: unión de aserciones y reglas. Contiene el conocimiento del dominio. Base de Datos: datos del problema particular que se quiere resolver. Memoria de Trabajo: base temporal donde queda la información deducida. Motor de Inferencias: activa reglas usando la base de datos y la memoria de trabajo. Trazador de Consultas: formula preguntas al usuario y registra respuestas. Trazador de Explicaciones: responde por qué se concluyó o preguntó algo. Manejador de Comunicaciones: interfaz de entrada/salida con el usuario.
No memorices como loro La Base de Conocimientos almacena reglas; el Motor de Inferencias las aplica. Si confundís depósito con motor, tu justificación queda floja. La regla está en la biblioteca; quien la usa para razonar es el motor.

3. La trampa: búsqueda en SET

Los métodos de búsqueda tienen sentido en un SET porque hay una estructura explícita que puede recorrerse: reglas, hechos, estados, consultas y conclusiones. Pero el recorrido no lo "hace" la base de conocimiento por sí sola.

PiezaRol correcto
Base de ConocimientosGuarda el dominio: aserciones, hechos y reglas.
Motor de InferenciasActiva reglas, decide qué aplicar y produce nuevas inferencias.
Memoria de TrabajoConserva lo deducido durante el caso actual.
Trazador de ExplicacionesJustifica qué reglas motivaron una conclusión o consulta.
Afirmación 4 — cómo defenderla
"Los Métodos de Búsqueda se aplican en un Sistema Experto Tradicional dentro de la Base de Conocimientos."

La intención es verdadera: en un SET hay conocimiento explícito que puede recorrerse con métodos de búsqueda. Pero la justificación precisa es que el recorrido lo realiza el motor de inferencias sobre la base de conocimientos, no la base como componente activo.

Respuesta de cinco renglones Verdadero con precisión. En un SET la base de conocimientos almacena hechos, aserciones y reglas del dominio. Los métodos de búsqueda sirven para recorrer/aplicar ese conocimiento, pero quien los ejecuta es el motor de inferencias. La memoria de trabajo guarda las conclusiones intermedias y el trazador de explicaciones justifica el resultado.

4. Dos principios de inferencia

La fuente de componentes indica que el motor de inferencias puede trabajar bajo dos principios:

PrincipioPregunta guíaDato importante
Datos conocidos Con lo que sé, ¿qué puedo concluir? La base de datos no puede estar vacía.
Hipótesis conocida Para probar esta hipótesis, ¿qué necesito saber? La base de datos puede estar vacía.

No necesitás convertir esto en un algoritmo para el parcial. Necesitás reconocer que el motor elige reglas y mueve el razonamiento, mientras los repositorios guardan conocimiento, datos y conclusiones.

5. Cuándo conviene SET, RNA o AG

El deck de construcción de sistemas inteligentes lo pone en la etapa de formalización: se elige el modelo implementable según objetivos, tarea, conocimiento y datos disponibles.

SET / SBC Clasificación o predicción con reglas completas y representables. Conocimiento explícito.
RNA Clasificación o predicción con ejemplos representativos. Conocimiento implícito en pesos.
AG Optimización combinatoria. Se buscan soluciones buenas en un espacio grande.
La mezcla que NO va No digas "todo SI usa base de conocimientos" como si fuera lo mismo. En la visión de la cátedra, el SET tiene base explícita; RNA y AG trabajan con conocimiento implícito. Por eso en SET tiene sentido hablar de reglas recorribles y explicaciones trazables.

6. Recuperación activa

¿Qué componente activa reglas para obtener nuevas conclusiones?

La base guarda reglas y aserciones; el motor las activa usando datos y memoria de trabajo.

Si tengo reglas completas para clasificar, ¿qué modelo conviene?

Reglas completas y conocimiento explícito apuntan a SBC/SET. RNA va con ejemplos representativos; AG va con optimización combinatoria.

De memoria: justificá la afirmación 4 en cinco renglones.

Verdadero con precisión. En un SET hay una base de conocimientos explícita con hechos y reglas que puede recorrerse. Los métodos de búsqueda se aplican para recorrer o activar ese conocimiento, pero los ejecuta el motor de inferencias. La memoria de trabajo guarda lo deducido y el trazador explica la conclusión.
